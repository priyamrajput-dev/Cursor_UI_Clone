# Cursor Landing Page Clone

A modern, responsive front-end recreation of the [Cursor](https://cursor.com) marketing website and interactive editor experience.

## ✨ Features & UI Highlights

- **Modern Typography**: Powered by Geist Sans and Geist Mono for code/editor realism.
- **Ambient Dark Theme**: Curated dark palette with subtle radial glows, glassmorphism, and border highlights.
- **Interactive Editor Showcase**:
  - macOS window chrome with interactive window controls.
  - Review queue sidebar with status badges and diff indicators (`+20 -3`).
  - Real-time task switching: click tasks to view live agent output.
  - Agent prompt bubble and diff summaries.
  - Interactive prompt input bar with `⌘K` / `Ctrl+K` keyboard shortcut autofocus.
  - Acme Labs preview frame with live status badges.
- **Fully Responsive**: Designed for fluid viewing across mobile (375px+), tablet (768px+), and wide desktop displays.
- **Trusted Logos & Testimonials**: Glassmorphic cards with quote styling, verified avatars, and featured highlights.
- **Mobile Navigation**: Collapsible hamburger menu with smooth transitions.

## 🔧 Tech Stack

- **HTML5**: Semantic document structuring and accessible navigation.
- **CSS3**: Modern CSS Grid, Flexbox, custom properties, and responsive breakpoints.
- **Vanilla JavaScript**: Zero dependencies, instant loading.
